2. Grundsätzliches zur Datenverarbeitung

Die Website der Nachtschicht dient ausschließlich der Information über das Simulationsprojekt und die Möglichkeit zur Teilnahme.

Auf dieser Website werden keine personenbezogenen Daten über Formulare erhoben oder gespeichert. Es werden insbesondere keine Benutzerkonten angelegt und keine Anmeldedaten für die Nachtschicht direkt auf dieser Website eingegeben.

Es werden von uns keine eigenen Analyse-, Tracking- oder Werbedienste eingesetzt.

3. Hosting über GitHub Pages

Diese Website wird über den Dienst GitHub Pages der GitHub, Inc. bereitgestellt.

Beim Aufruf einer über GitHub Pages bereitgestellten Website wird nach Angaben von GitHub die IP-Adresse der Besucher aus Sicherheitsgründen protokolliert und gespeichert. Diese Verarbeitung erfolgt durch GitHub als Betreiber des Hostingdienstes und nicht durch die Betreiber der Nachtschicht-Website selbst.

Weitere Informationen zur Verarbeitung personenbezogener Daten durch GitHub finden sich in der Datenschutzerklärung von GitHub.

4. Cookies und Tracking

Auf der Nachtschicht-Website werden keine eigenen Cookies gesetzt und keine eigenen Tracking- oder Analysewerkzeuge eingesetzt.

Die Website verwendet insbesondere keine Dienste wie Google Analytics, Matomo, Meta Pixel oder vergleichbare Analyse- und Marketingdienste.

Soweit GitHub im Rahmen des Betriebs seiner eigenen Infrastruktur technisch erforderliche Cookies oder vergleichbare Technologien einsetzt, erfolgt dies durch GitHub und liegt außerhalb des Einflussbereichs der Betreiber der Nachtschicht-Website.

5. Anmeldung zur Nachtschicht

Eine Anmeldung zur Nachtschicht erfolgt nicht über diese Website.

Auf der Website werden lediglich Informationen zur Veranstaltung bereitgestellt und gegebenenfalls Links zu einer externen Anmeldeseite angeboten. Die Eingabe und Verarbeitung personenbezogener Daten im Rahmen der Anmeldung findet ausschließlich auf der jeweiligen externen Plattform statt.

Für die dort stattfindende Verarbeitung personenbezogener Daten gelten die Datenschutzbestimmungen des jeweiligen Anbieters.

6. Kontaktaufnahme per E-Mail

Für Fragen zur Nachtschicht wird die E-Mail-Adresse staeps.nachtschicht@med.uni-goettingen.de angegeben.

Bei einer Kontaktaufnahme per E-Mail werden die vom Absender übermittelten personenbezogenen Daten verarbeitet, soweit dies zur Bearbeitung der Anfrage erforderlich ist.

Die Verarbeitung erfolgt ausschließlich zur Bearbeitung und Beantwortung der jeweiligen Anfrage. Eine darüber hinausgehende Nutzung der Daten findet nicht statt, soweit keine gesetzliche Verpflichtung zur Aufbewahrung oder Verarbeitung besteht.

7. Fotos und Bildmaterial

Auf dieser Website werden Fotografien veröffentlicht, die im Rahmen der Nachtschicht bzw. im Zusammenhang mit dem Simulationsprojekt entstanden sind. Auf den Fotografien können Teilnehmer:innen, Mitarbeiter:innen, Tutor:innen und weitere an der Nachtschicht beteiligte Personen erkennbar abgebildet sein.

Die Veröffentlichung der Fotografien erfolgt auf Grundlage einer schriftlichen Einwilligung der jeweils abgebildeten Personen. Die Einwilligung umfasst die Aufnahme und die Veröffentlichung der Fotografien auf der Website der Nachtschicht zu Zwecken der Information über das Projekt und der Darstellung der Durchführung und der Lernmöglichkeiten der Nachtschicht.

Die Fotografien werden ausschließlich im Zusammenhang mit der Information über das Projekt, der Darstellung der Nachtschicht und der Bewerbung des Veranstaltungsangebots verwendet.

Eine erteilte Einwilligung kann mit Wirkung für die Zukunft widerrufen werden. Die Rechtmäßigkeit der bis zum Widerruf erfolgten Verarbeitung bleibt hiervon unberührt. Im Falle eines Widerrufs werden betroffene Fotografien, soweit dies möglich und zumutbar ist, von der Website entfernt bzw. durch geeignete Maßnahmen ersetzt.
